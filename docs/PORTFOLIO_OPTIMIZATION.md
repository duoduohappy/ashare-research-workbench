# 组合算法实验与滚动样本外对照

本模块在「组合配置与风控」页面展示，比较同一股票池下的四种配置方法。它是连续权重的研究近似，不连接账户，也不创建或启用运营策略版本。

## 使用

1. 安装 `requirements.txt` 并重启 `python server.py`，刷新浏览器。
2. 加载行情或明确标注的合成演示，进入「组合配置与风控」。
3. 在「组合算法实验」输入 2–8 只不同股票，选择协方差估计、训练窗口、调仓间隔、上限及成本。
4. 点击「运行四算法样本外对照」，查看七张图与逐次调仓审计。

可读取上方手工组合的股票代码，但实验独立计算目标权重。样本外起点留空时，在训练数据充足后的下一个共同观测日开始；指定起点前必须已有完整训练窗口。至少保留 22 个样本外共同观测日。

默认值仅为研究示例：126 个训练收益、21 个共同观测日调仓、单股上限 50%、每侧 10 bp 情景成本、30 万研究资金。界面不自动搜索参数或选择表现最好的算法。

## 四种方法

记估计日频协方差为 C，完全投资权重为 w。

| 方法 | 目标 | 约束或区别 |
| --- | --- | --- |
| 等权 | 每只股票 1/n | 作为统一调仓和成本口径的基线 |
| 波动倒数 | 与 1 / sqrt(C_ii) 成比例 | 超过仓位上限后按比例再分配，不是完整风险平价 |
| 风险平价（约束近似） | 最小化 sum((RC_i − 1/n)^2) | RC_i = w_i(Cw)_i / (w' C w)，使用完整协方差 |
| 受约束最小方差 | 最小化 w' C w | 用正定风险矩阵做约束二次目标求解 |

所有方法只做多、无杠杆、权重合计 100%，目标权重不超过单股上限。若股票数 × 上限小于 100%，请求被拒绝。等权、波动倒数同样受约束。

优化使用 SciPy SLSQP；最小方差使用等权起点，风险平价使用等权和受限波动倒数两个确定起点，择已收敛且满足预算及仓位约束的较低目标值。解析梯度、预算约束和边界均显式指定。不收敛则报错，不静默换成其他算法。风险平价目标不保证全局最优；求解成功也不代表风险贡献精确均分。

页面披露最大等风险偏差 max(abs(RC_i − 1/n))，按百分点展示。阈值 1e-4 对应 0.01 个百分点，低于该值才标记达到等风险容差。存在约束、强相关或负边际贡献时可能不满足；风险贡献可能为负。这里的偏差只度量风险均分，不是收益预测误差。

## 协方差估计

- Ledoit–Wolf：调用 scikit-learn 的估计器，向均匀对角目标收缩，披露实际收缩系数。
- 样本协方差：按样本自由度 1 估计。
- 两者均对称化；若最小特征值小于 `max(平均对角方差 × 1e-8, 1e-16)`，补足对角正则，披露补充值和正则后的条件数。
- 若训练期平均方差小于 1e-16，停止该实验；不把缺乏波动解释为无风险投资机会。

预估年化波动采用 sqrt(252 × w' C w)。相关性图来自当前所选估计矩阵，不一定等于原始样本相关性。正则改善数值可解性，不保证风险估计正确。

## 信号和执行时间

先截断至共享查看日期，再取所有股票日线的日期交集，不前向补值。

每次日 t 收盘，用截至 t 的最近 L 个收盘到收盘收益估计协方差，形成全部四种目标；在下一共同观测日开盘进行研究调仓。目标形成不读取执行日的收盘或后续收益。无指定起点时，首个执行日为第 L+2 根共同日线。

开盘研究价格 = 原始开盘 × 当日复权收盘 / 原始收盘，持仓以复权经济单位计价。首次调仓前是现金，不能获得买入前的隔夜涨幅。调仓间持有单位数不变，权重自然漂移；仓位上限只限制调仓目标，不持续约束漂移权重。

最后已知收盘另行估计「最新研究目标」，供下一可用开盘参考。其执行日为空，不计入历史净值；历史账户的当前实际权重单独列出，避免将最新目标误认为历史成交。

## 成本与资金核对

成本为买入额与卖出额合计 × `cost_bps / 10000`，首次建仓也扣成本。它是统一的情景参数，不模拟各日期实际税费、最低佣金或盘口滑点。

调仓前净资产记为 V，原持仓开盘市值为 H_i，成本比例为 c。调仓后净资产 A 满足：

`A + c × sum(abs(w_i × A − H_i)) = V`

在 [0,V] 内二分求解，再按 A 分配目标资产，因此同时满足资金预算和费用扣除。每次记录调仓前资产、调仓后资产、成本、成交名义额及双向换手；允许双向换手超过 100%。累计成本占初始资金是金额比例，不等于收益损失的精确归因。

净值初始点为首次执行前一共同观测日的 1，包含首次建仓成本的回撤；无期末强制卖出。收益、年化和波动均从同一净值口径计算，现金不计利息。

## 七张图及导出

净值、回撤、最新目标权重热力图、估计风险贡献热力图、逐次换手、累计成本、相关性矩阵。明细提供统一表现表、风险均分残差、实际漂移权重、训练/信号/执行边界及调仓预算记录。

导出 JSON 包含配置、代码顺序、每日净值和回撤、全部调仓、训练边界、估计元数据与求解状态。数据或参数变化后旧结果失效，旧日期请求不能覆盖新日期结果。

## 验证和限制

`python -m unittest test_portfolio_optimization -v` 检验解析对角解、相关性影响、仓位边界、不可达风险均分、奇异协方差正则、不收敛报错、预算与成本、日期截断不变性，以及首次买入前隔夜跳空不获利。界面控制逻辑测试另外验证请求、图表调用、不可行参数和迟到响应失效。

这个小规模手动股票池具有幸存者偏差，未做行业或市值约束，没有交易容量保证。共同日期可能跨停牌、缺失或休市间隔，252 日年化是近似。公共复权数据是当前修订版本，不是严格 PIT；分红、送股与复权经济单位不等于可逐笔对账的真实账户。

未执行整手、T+1、涨跌停、停牌排队和真实公司行动规则。连续股数净值和统一成本仅用于方法比较，不是可执行成交回测，不能导入运营版本自动交易。样本外历史表现也不能证明未来有效；应在独立时期和持续模拟中另行验证。
