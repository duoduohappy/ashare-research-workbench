# 验证说明

本项目的验证分为计算测试、无浏览器界面逻辑测试、隔离端到端验收和外部数据适配验证。

## 已完成的验证范围

- 105 项单元测试：概率归一化、无未来信息、时间切分、费用与成交边界、组合计算、持仓 FIFO、数据闸门、版本与任务持久化、模拟日事务幂等、收益归因、风险暂停、快照完整性、备份校验、隔离恢复和后台停止。
- 无浏览器界面逻辑测试：模块切换、共享日期、结果失效、图表调用、运营监控与日报图表渲染逻辑。
- 隔离端到端验收：研究任务排队与验证、冻结快照复现、HTTP 服务停止后后台继续、20 个合成交易日日报、逐日收益核对、重复请求与推进幂等、备份恢复、策略暂停和心跳。
- 真实单标的日线适配与质量闸门验证：腾讯单区间前复权及原始日线，与新浪原始收盘核对。外部接口后续是否可用仍需持续检查。

- 新增因子诊断测试：已知相关系数、并列秩与无定义截面、分组算术、日期截断不变性、共同日期交集、训练期选择不读取测试标签，以及折内/跨折非重叠收益区间。机器学习测试同时核对逐折指标和标签截止边界。

- 新增 10 项组合优化测试：对角解析解、相关性、仓位上限和不可达等风险、收缩/奇异正则、求解失败、双向成本预算、未来截断不变性、训练边界及首次建仓的隔夜跳空。界面逻辑测试覆盖组合实验的四算法图表/表格、不可行仓位、共享日期和迟到响应失效。

- 新增 9 项状态研究测试：前向概率与穷举路径、过滤与未来观测隔离、EM 参数与未收敛标记、历史预测稳定、后续价格扰动隔离、评分与概率预算、训练标准化边界、导出参数重算预测和平滑/无效输入。界面测试覆盖三模型图表、未完成标签、参数失效和迟到响应。

- 新增 9 项策略稳健性测试：训练选参和独立资金、完整折稳定与日期截断、测试扰动隔离、并列选择、冻结参数成本复算、额外信号延迟、区块重采样复现、首日成本及输入拒绝。界面测试验证成本/延迟图表、迟到请求；运营状态读取合并并发请求，写操作完成后仍获取新状态。

- 新增 8 项研究证据测试：内容标识与元数据保留、禁止行情请求下四类研究复算、环境/源码变化阻断、损坏记录排除、结果不一致、版本变化及参数/路径拒绝。隔离 HTTP 界面逻辑验证冻结、保存、严格复算、版本比较、导出与独立证据日期；Windows 工作目录实际保存流程验证使用原子重命名。

## 如何重新验证

1. 安装 `requirements.txt`。
2. 运行 `python -m unittest -v`。
3. 启动 `python server.py`，运行 `node test_ui.cjs`（需要 Node.js）。
4. 运行 `python acceptance_ops.py`，执行独立环境的端到端验收。

前端升级回归还需执行 `python build_ui.py --check`。启动服务后运行 `node test_browser_bootstrap.cjs` 与 `node test_browser_bootstrap.cjs --legacy-fixture`；前者验证当前接口兼容性，后者只提供旧版静态路由并隐藏新增接口，验证脚本引导、市场页渲染及明确重启提示。`test_ui.cjs` 也改为从 HTTP HTML 读取脚本清单、逐个通过 HTTP 加载，不再以本地文件导入绕过静态路由。

这些检查覆盖升级期间“前端文件已更新、Python 进程仍为旧版”导致的新增脚本 404 和未定义函数问题；不等于已重启用户的后台进程，也不代表真实浏览器视觉验收完成。

`OPERATIONS_ACCEPTANCE.json`、`LIVE_GATE_VALIDATION.json`、测试生成的数据库与快照属于本机运行产物，不随仓库发布。运行验收脚本可重新生成端到端记录。

## 证据边界

- 20 个合成模拟日属于受控验收，不是连续 20 个真实交易日的线上运行证明。
- 界面逻辑测试不等于真实浏览器视觉、交互和可访问性验收；新历史时点面板已完成 Playwright 合成数据下的七图渲染、两种排序与哈希复算检查；其他页面的完整跨浏览器视觉验收仍待完成。
- 尚需多周真实模拟观察、硬断电恢复、不同机器灾备切换及外部数据服务稳定性验证。
- 当前不存在实盘账户接入或实盘交易验收。

## 历史时点与成交研究验收

新增 15 项测试覆盖历史池、财报版本可用时间、未来扰动隔离、退市处置、缺行与停牌区别、T+1 和零股、开盘容量、规则生效日、损坏导入及复算。全量共 105 项测试通过。严格研究使用隔离数据根目录验收；合成数据通过不代表真实历史主表、退市样本或原始财报版本已经完整。操作说明见 POINT_IN_TIME.md。
