# 因子有效性与滚动样本外验证

该功能用于检查价格因子的历史证据，不执行委托，不修改运营策略版本或模拟账户。

## 如何使用

1. 启动 `python server.py`，加载真实行情或明确标注的合成演示。
2. 进入「多因子选股」，输入 5–8 个不同股票代码，选择共享查看日期。
3. 在「因子有效性与滚动样本外验证」中选择因子及远期窗口，点击验证。
4. 查看五张图：滚动 IC、因子衰减、分组均值、分组历史远期收益、训练与样本外对照。
5. 展开验证边界与逐日明细，或导出完整 JSON 核对原始数值。

默认池提供六个示例代码，仅用于展示输入方式，不构成推荐。最少 240 个共同观测日，最多保留最近 504 个已完成标签的信号日。改变候选池、参数或共享日期后结果失效；旧请求返回不会覆盖新日期结果。

## 因子与标签

所有价格使用已有行情的复权收盘价，先截断至查看日期，再按股票池共同日期交集对齐。

| 因子 | 计算方式 | 高分含义 |
| --- | --- | --- |
| 20 日动量 | P(t) / P(t−20) − 1 | 近期收益更高 |
| 5 日反转 | −[P(t) / P(t−5) − 1] | 近期收益更低 |
| 20 日低波 | 最近 20 个单期收益的样本标准差取负 | 近期波动更低 |

标签为 P(t+h) / P(t) − 1，h 为 1、5 或 20 个共同观测步数。为保证衰减图可比较，三个窗口使用完全相同的信号日期；最后 20 个共同观测日不作新信号日期。相应标签结束日必须不晚于查看日期。

这些标签包含因子形成当日收盘到未来收盘的收益，是描述性指标。无法假定看到收盘信号后仍可按同一收盘成交，因此不展示交易净值，也不报告策略夏普或年化收益。

## IC、分组与缺失值

- IC：每个信号日，横截面因子值与远期收益的 Pearson 相关系数。
- Rank IC：因子值与远期收益各自转为平均秩后计算相关系数，即 Spearman 秩相关。
- Rank ICIR：有效逐日 Rank IC 均值 / 样本标准差；不年化。标准差接近零时显示无定义。
- 三组收益：按因子从低到高分为三组，每组等权平均远期收益；高低组差为高组减低组。5/6/7/8 只股票的分组数量分别为 1/2/2、2/2/2、2/2/3、2/3/3。
- 若因子值在分组边界并列，整个截面的分组结果为空，避免按代码任意拆组。常数因子或常数标签的相关系数为空，图表显示无有效观测，不伪造为零。
- IC 时序图为最近 20 个信号日内有效系数的滚动均值；最少经过 20 个信号日才显示。有效日期和有效分组数单独披露。

普通逐日图的多日标签会重叠，股票之间也可能高度相关；不据此给出独立样本 t 检验或“有效因子”自动评级。所选因子的全样本图属于探索性分析，不能算样本外表现。

## 滚动样本外验证

每折使用最多 126 个训练信号日，后续测试窗为 42 个信号日。训练样本的标签截止日必须严格早于首个测试信号日；跨界标签被剔除。

训练阶段计算三个候选因子的平均 Rank IC，至少有 60 个有效截面才参与选择。按平均 Rank IC 绝对值选因子，正反方向也只由训练均值决定；测试期内不重新选择。三因子及参数固定，没有测试期调参。

测试按全局统一的 h 步间隔取样，使同一窗口的收益区间在折内和折间都不重叠（允许前一期结束日等于下一期起点）。反向选择时同时反转 IC 符号和分组顺序。页面保留训练原始均值的定向结果、测试指标和各折所选因子，不把多折拼接为交易净值。尾部不足 42 个信号日不形成测试折。

不重叠标签仍不意味着统计独立。反复查看结果再修改候选池和方法，会引入人为选择偏差；应另保留未参与研究的时期或持续模拟观察。

## 机器学习模块的增强

保留已有岭回归、随机森林和直方图梯度提升及三段滚动验证。新增每折模型 MAE / 训练均值基线 MAE 对照、逐日横截面 Rank IC，以及训练、标签截止和测试区间明细；导出结果包含股票代码、折编号和逐日指标。横截面少于三只股票或截面常数时 Rank IC 无定义。其五日逐日标签仍有重叠，与本页因子测试的非重叠抽样口径不同。

## 证据边界

当前候选池很小，且由用户事后选定，有幸存者偏差；未做行业、市值中性化或全市场因子覆盖。当前财报评分不会回填到历史，本功能不检验价值、质量、成长或红利等财务因子。

公共行情为当前修订版本，并非严格 PIT。日期交集可跳过停牌或缺失日期，观测步数不能保证等于市场连续交易日；未模拟费用、涨跌停、公司行动、卖空和成交容量。真实数据稳定性和长期样本外运行仍需验证，合成演示仅证明程序路径可运行。

方法参考：[Alphalens 因子分析](https://github.com/quantopian/alphalens)、[scikit-learn 时间序列切分及 gap 参数](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)。本模块自行实现明确标签截止日的隔离规则，没有直接调用 Alphalens 或 TimeSeriesSplit。
