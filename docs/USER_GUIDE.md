# 使用说明与计算口径

本地可视化分析工具，基于 Markov Hedge Fund Method 的可观测三状态思路独立实现。Python 3.10+，依赖 requests、NumPy 和 scikit-learn，不需要 API 密钥。

## 启动

Windows 双击 `start.bat`，首次缺少依赖会自动安装。或在本目录运行 `python -m pip install -r requirements.txt`，再运行 `python server.py`，打开 http://127.0.0.1:8876 。保持终端开启，按 Ctrl+C 停止。端口占用时用 `python server.py --port 8877` 并打开相应地址。

## 功能

- 输入六位沪深股票代码；快捷选择茅台、平安银行、宁德时代。
- 自动获取约五年后复权日线和最新未复权报价：最新模式每 60 秒刷新报价，每 15 分钟刷新日线；页面关闭时不运行。
- 日期选择、逐交易日前进后退、播放暂停、速度和回放区间设置。
- 价格及状态背景、逐日重估的转移矩阵、下一日状态概率、稳态分布。
- 修改回看周期与阈值，点击加载重新计算；导出所选日及之前的数据。
- 网络失败显示错误或明确标注的过期缓存；离线可手动进入合成演示模式，不会把演示伪装为真实行情。

## 数据及口径

腾讯财经公共 HTTP 行情接口，非官方授权商业数据接入，可能限流、延迟、修订或失效。无可用性保证。北交所暂未支持。历史缓存位于 `cache/`，正常复用一小时，手动刷新或自动轮询会重新尝试获取。

确认状态只采用已收盘日线，当天日线在北京时间 15:10 后才可纳入且仍取决于上游更新；盘中卡片展示报价及供应商时间，不与复权价格拼接。不提供盘中暂定状态。

历史回放以所选日期为截止重估，只显示当时及之前的曲线、概率与导出数据。日线是供应商当前修订版本（后复权），并非逐日保存的历史数据版本；不承诺严格的 point-in-time 复原。真实回放跟随供应商实际交易日；演示只是固定随机种子生成的工作日价格，不代表真实证券，未模拟法定休市。

标记：过去 N 日普通累计收益 > 阈值为牛市、< 负阈值为熊市，否则震荡。矩阵加 0.5 Dirichlet 平滑，修复缺失状态行。该平滑使结果与上游未平滑实现略有差异。稳态分布通过迭代求解。状态概率不等于下一日涨跌概率。样本不足时估计不稳定。

## 范围

本版提供行情、历史回放、趋势风险指标和研究回测。不连接券商、不下单。回测适用范围和近似限制见下方新增功能说明，不能用其输出替代投资判断。

运行 `python -m unittest -v`，检查无未来信息、概率归一化、缺失状态、日期清洗、参数校验和真实行情适配格式。真实网络接口须另行联网验证。

## 新增：趋势、风险与研究回测

- 曲线叠加 MA20（金色）、MA60（紫色）；趋势条件为收盘价高于 MA60 且 20 日动量大于零。
- 风险卡片：20 日年化波动率、从已加载历史峰值计算的回撤、当前成交量相对前 20 日均量，以及收盘价估算成交额（非供应商实际成交额）。
- 三策略统一区间：买入持有、趋势策略、趋势加马尔可夫过滤。至少预留 252 个转移样本，不进行参数优化。
- 选择回测起点，结束日为当前回放选定日期；回到更早日期会隐藏未来的回测结果，防止泄漏。参数修改后必须重新运行。
- 执行：前日收盘信号，下一根可交易日线的开盘价，加可配置单边滑点。仅做多/空仓，每日最多一次操作，不能卖出当日买入持仓；按最小股数模拟买入。科创板至少 200 股，之后 1 股递增；其他支持股票为 100 股整数倍。
- 近似涨跌停：按所选 5%/10%/20% 场景，以分红除权参考价近似计算；涨停开盘不买、跌停开盘不卖。这个规则比实际封板可成交条件保守，不使用当日最高最低价倒推成交。没有历史 ST 状态与 IPO 特别交易规则，无法精确复原这些日期，请选择普通已上市股票与合适区间。
- 停牌：显式零成交量不成交；缺失停牌日没有委托或收益观测。可得日线的年化波动/夏普按 252 计算，长停牌会影响可比性；年化收益按自然日计算。
- 费用：双向佣金默认万分之三，最低 5 元（可调整，视为已包含经手等其他规费）；过户费 2022-04-29 前万分之 0.2、之后万分之 0.1；卖出印花税 2023-08-28 前千分之一、之后万分之五。默认单边滑点千分之一。
- 资金默认 30 万，避免高价股票不足一手导致三条曲线都空仓；资金不足会显示在受阻记录里。
- 公司行动：用后复权经济单位估值，股数按当日复权因子换算，隐含分红再投资和等价持股，不是逐笔现金分红/送股处理，未计分红税。**本回测是研究近似，不是可对账实盘收益。**
- 净值计入初始资金与首次费用回撤；期末持仓按收盘估值，未强制平仓。可导出三策略完整交易、费用与受阻记录 JSON。
- 本版支持沪深普通股票，暂不支持 ETF、B 股、指数或北交所。行情仍是当前修订版本，未提供严格历史数据版本复原。


测试：`python -m unittest -v`；启动服务器后运行 `node test_ui.cjs`（可选，需 Node.js）。

## 模块化工作台

左侧七个导航类别：多因子选股、趋势与反转、市场状态识别、机器学习选股、组合配置与风控、交易执行、文本分析。当前默认进入市场状态识别。切换模块保留当前股票、回放日期、模型参数及回测设置。

已接入：
- 趋势与反转：均线/动量及既有三策略回测；新增前 20 日收盘区间突破、20 日价格标准分。后两者仅作描述观察，未作为独立策略回测。
- 市场状态识别：主图提供扩展计数马尔可夫状态、矩阵、概率、稳态分布及共享日期回放；下方独立实验提供 HMM、KMeans 与固定训练窗阈值马尔可夫的滚动样本外对照，见「状态算法研究」。
- 组合配置与风控：输入 2–8 个不重复沪深股票代码和初始权重，权重合计不超过 100%，其余为无息现金。真实数据与合成演示严格分开。组合起点到当前查看日期，取所有股票的共同日线，计算一次配置、之后不再平衡的后复权持有净值、累计收益、回撤、当前权重、相关性与风险贡献。

组合波动及风险贡献使用最近最多 60 个共同收益观测和当前权重；波动倒数参考仅按各股票波动率倒数归一化，未纳入相关性，不等于完整风险平价或最优配置。风险贡献可以为负。零波动时相关性与风险贡献显示无可用值。组合研究未计手续费、整手、成交限制或真实公司行动，不能当作单股执行回测。历史成分为手动选择，不提供无幸存者偏差股票池。

调整组合输入、共享数据或回放日期后会使旧组合结果失效，避免展示未来结果。可导出 JSON。新增四类模块现已接入，下节说明具体实现与限制。

新增测试覆盖组合现金与权重一致性、共同日期交集、零波动、非法权重、无未来数据，以及模块切换保持日期、规划页标记、组合渲染与结果失效。


## 四类扩展模块与新增图表

- 多因子：自动从东方财富获取公告日期早于查看日的财务报告，与腾讯历史价格组合计算 B/P、累计 ROE、营收同比、动量、低波评分。红利或其他财务项可用带 published_at 的 CSV 补充。所有候选共同缺失的因子剔除并显示，不伪造股息率；覆盖不足会明确提示。财报是当前修订版本，不承诺严格 PIT。提供因子得分热力图和排名。
- 机器学习：岭回归、随机森林、直方图梯度提升三种实际模型（不是 LightGBM/XGBoost）。五项价格成交特征，预测未来五个观测日收益；最近 60 个有标签日期分三段滚动验证，训练前隔离标签跨界，最终模型只使用截至所选日已知的标签。提供预测排序柱图、预测/实际散点图、MAE 与均值基线等指标。没有有效性承诺，不是收益回测。
- 执行：TWAP、前日量分布 VWAP、POV、冰山离线模拟。使用近期公共分钟行情或用户分钟 CSV（time,open,close,volume；volume 单位为股），可切换合成演示。上游忽略日期时会过滤未来分钟，缺失目标日则报错。VWAP 要求前日分钟覆盖完整；不使用当日总量预知排程。显示累计成交曲线、费用和未完成量，可导出全部子单；没有实盘接口，卖出假定已有可卖持仓。
- 文本：搜索资讯；新闻搜索接口变化或无匹配时回退公告列表，点击公告读取供应商正文并校验发布日期。接口仅返回近期列表，历史覆盖不足可粘贴原文。默认本地词典、简单否定识别、原文摘句与数字提取；正负词频和关键词柱图明确属于描述统计，非涨跌概率。可填写本机已安装的 Ollama 模型名称，调用固定 localhost:11434 生成额外摘要；未配置时不调用 AI，不自动安装模型、不上传外部大模型。本地模型不可用会报错，不伪装生成摘要。
- 组合增加当前权重和风险贡献柱图，保留相关性表格热力着色及净值图。表格用于精确核对，图表用于快速比较。

输入或共享股票/日期改变后隐藏旧结果，避免误用未来分析。所有扩展结果支持 JSON 导出。公共接口可能失效或限流，演示数据必须手动启用，绝不自动替代真实数据。文本发布日为用户输入时由用户确认真实性。财务补充数据覆盖项以用户输入为准，务必保持指标口径和披露时间一致。

联网验证已跑通财报五项可用因子、三种机器学习模型、真实分钟 TWAP 和公告正文接口；部分公告请求会受网络限制，错误会保留在页面。Ollama 适配器已实现，本机未配置模型，尚未进行真实大模型推理验收。浏览器控制环境受限，图表已通过无浏览器渲染逻辑测试，未完成浏览器视觉验收。


## 八个新增工作区（v5）

导航按“市场与标的 / 策略研究 / 组合与执行 / 信息与诊断”分组，总计十五个模块。八个新增模块采用统一的四张指标卡、双列图表、大图跨列布局；精确表格和计算口径默认折叠。移动端图表自动单列，热力图与曲线支持鼠标悬停查看数据。

1. 市场全景：主源东财沪深快照，备用新浪 A 股快照（可能含北交所）。分页去重，显示有效样本/供应商总数及覆盖率；抓取有时限，缺页明确标注。新浪仅提供时分秒时，将行情所属日期标记为未核验，抓取时间不当作行情时间。展示涨跌环图、涨幅分布、成交额前 80 股票的等面积热力图。独立于历史回放日，不能当作历史市场快照。
2. 行业与板块轮动：使用八只固定行业 ETF 代理，自动读取名称和后复权日线。展示相对 20 日/5 日收益轨迹、5/20/60 日收益热力图及归一化走势。不是纯行业指数或资金流，不是标准 RRG；固定样本存在事后选择与存续偏差。失败代理被跳过并提示，至少两只才计算。
3. 股票筛选与自选池：对输入的 1–8 只股票按 20 日动量、波动、历史回撤、MA60 条件筛选，展示漏斗、散点、收益/回撤热力图。自选池按名称保存在本地 SQLite，可同步至多因子、机器学习和组合输入。不是全市场无偏筛选。
4. 财务与估值研究：提取截至所选日之前已披露财报，图示累计营收、利润、ROE、每股现金流及每股收益；逐日按可得报告计算 PB，足够报告可构造正 EPS TTM 才计算 PE。显示有效历史估值分位。当前修订数据非严格 PIT，累计指标不冒充单季度，缺失值不补造。
5. 事件与公告日历：自动公告发布时间轴、类型分布、前 60 日至后 30 日已知事件日历、已有完整前后各五日的事件窗口曲线。可用 CSV（date,published_at,kind,title）补充实际分红或解禁日；只有已披露事件可见。自动发布日期不冒充真实事件日，未检索到不等于无事件，走势不表示因果关系。
6. 策略实验室：组合均线和动量参数，可附加状态过滤，最多十二组。固定 70%/30% 时间切分，仅以训练收益及回撤选参，样本外只评估所选参数。图示训练参数热力图、样本外净值及回撤。成本与限制沿用研究回测；反复查看样本外仍会污染验证，不是自动发现稳定收益。
7. 模拟持仓与复盘：固定初始模拟资金 30 万，真实模式手工录入模拟成交并本地保存；与券商账户无连接。校验成交日、原始日线价格范围、最小申报单位、现金与 T+1，FIFO 计算已卖出委托盈亏及持有天数。图示净值、已实现盈亏和持有时间散点。按截止日最近原始收盘估值，未处理分红送转或出入金，非真实账户收益；演示模式不写账。
8. 数据质量与来源：检查当前规范化数据的重复日期、无效价格、OHLC、零量观测、来源、获取时间及缓存状态；以股票日期并集绘制覆盖日历，缺格可能是上市/停牌或缺失，未接完整交易日历，不能直接判为缺失错误。

本地状态保存在同目录 `workspace.sqlite3`，仅存自选池和手工模拟交易。需要备份时单独备份此文件；源码压缩包不包含该数据库或行情缓存，避免把用户记录打包。数据库写入事务化，失败成交会回滚。测试采用临时独立数据库，不改用户账本。

验证：原有计算与新模块共 34 项单元测试，另有全部十五模块的无浏览器渲染与接口逻辑测试。真实数据联调覆盖财务、ETF 代理、筛选、事件、参数实验、诊断；市场备源实测获取 5579 条有效记录，但行情所属日期仍未核验。浏览器工具不可用，未完成像素级视觉验收。


## 运营闭环（v6）：研究任务与持续模拟

### 操作路径

1. 左侧进入「研究任务与持续模拟」。后台状态应显示有效心跳。
2. 新建版本，选择真实行情或明确隔离的合成演示，绑定股票池、MA、动量、状态参数与风险阈值。参数不可原地修改，同名配置保存为新版本。
3. 选择已收盘截止日，提交研究验证。请求立即持久入队，由后台执行，页面关闭不丢任务。
4. 查看任务详情中的质量闸门、数据快照哈希、引擎源码清单与验证结果。只有数据和流程合格才标记「已验证」；策略亏损不会被隐藏，验证不代表策略有效。
5. 对最近已收盘日完成验证后，手工「启动模拟」。每个版本创建独立账户，以验证截止日为初始游标，从之后的新交易日开始；不补造历史成交。
6. 后台在电脑开机且网络可用时定期检查并推进新交易日，生成信号、模拟委托、成交或受阻原因、费用、净值与逐股归因日报。
7. 可暂停、归档、导出任务，或使用冻结快照和同版引擎复现。页面默认仅显示近 60 个任务、近 250 条日报；全量保留在本地运营库与备份。

### 严格运营数据路径

旧的十五个研究模块继续支持浏览与探索，其结果不自动获得运营认证。新运营任务单独获取最近约 640 根、单区间前复权与原始腾讯日线，不沿用旧年度后复权拼接；与新浪原始收盘交叉核对。支持范围为普通沪深主板、创业板和科创板；当前 ST/退市标识拒绝运行。

质量闸门检查：交易日历覆盖及七日缓存期限、北京时间 15:20 收盘缓冲、十二小时获取期限、非过期行情、日期排序和唯一性、至少 300 日预热、最新已核验交易日、OHLC/有限正价格、完整交易日覆盖，以及独立来源收盘差不超过两分。停牌状态未能核验、缺日、来源不一致或日历不可用都会阻断，不把旧价当新价。日历适配器在有超时上限的独立辅助进程获取。真实单标的闸门验证记录为 `LIVE_GATE_VALIDATION.json`。

冻结的是“获取当时的供应商当前修订版本”，不是历史原始 PIT 数据。过去时点的研究仍可能存在修订、幸存者偏差和样本选择问题，不能把可复现当成无偏回测。合成版本使用工作日生成数据，未模拟法定休市，只用于功能验证，不能转换为真实数据版本。

### 模拟账户与风险

每个日事务同时提交：模拟委托、账户、游标和归因日报。按版本＋交易日＋代码建立唯一约束，重复任务不能增加同日订单或日报；请求编号也防重复提交。先卖后买，限制现金、单股权重、每日委托数、最小申报单位和 T+1；开盘封板保守不成交。普通主板固定 10%、创业/科创固定 20% 场景，不支持特殊 IPO、历史 ST 等未覆盖规则。

使用前日收盘信号与次日开盘离线价格，包含可追溯的费用假设。净值增量必须与逐股收益归因一致，差额超两分则事务回滚。最大回撤触发暂停；持仓公司行动/复权因子变化或历史原始价格修订也阻断，需要人工核对，不静默处理分红、送转或重置损失。数据或执行错误会暂停该版本，须新近研究验证后手工恢复；已触发最大回撤的版本不能直接恢复。后台重启从已提交游标继续，未提交事务由 SQLite 回滚。

这仍然是本地离线模拟，没有券商 API、实盘资金或真实成交保证。

### 独立后台与停止方式

启动 `server.py` 会启动一个隐藏的 `ops_worker.py` 独立进程。电脑关机、睡眠、断网期间不能运行，未配置为开机自启或云托管。数据库租约及心跳保证单个数据目录只有一个有效工作进程。浏览器或 HTTP 服务关闭后，后台仍可处理已排队任务；再次打开 `start.bat` 可查看记录。

运营台可暂停全部新任务，也可暂停单一策略。前者不强制中断已开始的任务；后者在当前日事务提交后停止下一日推进。「结束后台进程」先暂停调度，再请求进程在当前任务完成后退出。再次启动后台不会自动开启已暂停的调度。不要直接复制正在写入的 SQLite 文件作为备份。

### 持久记录、备份与恢复

- `operations.sqlite3`：不可变策略、持久队列、运行记录、独立模拟账户、订单、日报、日志、租约和配置。
- `operations_store/`：内容寻址数据快照、交易日历、引擎源码及 Python 版本清单。
- `workspace.sqlite3`：原有自选池与手工模拟账本，与持续模拟账户分开。
- `backups/`：校验备份；每天首次成功任务后自动备份，有新模拟日事务提交（包括部分推进后受阻）时追加备份，也可手动创建。当前没有自动删除保留策略，需要定期归档并监控磁盘容量。

备份使用 SQLite 在线备份，维护标记阻止新运营任务，运行中的策略任务未结束时拒绝备份。两个独立数据库各自保证事务一致，不承诺跨库原子时点。压缩包完成校验后才原子发布，含成员 SHA-256 清单；不含可重建行情缓存。

恢复按钮只恢复到 `recovered/<唯一编号>/` 隔离副本，不覆盖当前数据。检查成员、路径、大小上限 500 MB、校验和及 SQLite 完整性，恢复后清理租约、关闭调度、暂停模拟版本。副本核对完后，停止旧 HTTP 服务，使用界面给出的 `python server.py --data-root <恢复路径>` 命令启动副本；须重新验证后再启用。恢复演练不等于已完成所有机器环境下的灾备切换验收。

### 验证与剩余上线条件

`python -m unittest -v` 共 47 项测试；`node test_ui.cjs` 覆盖原有模块及运营控制台渲染逻辑。隔离端到端验收记录见 `OPERATIONS_ACCEPTANCE.json`：持久研究排队、质量闸门、冻结重放、关闭 HTTP 服务后后台继续、模拟 20 日事务恢复、归因核对、重复请求和交易日幂等、备份恢复及策略暂停。验收不改用户账户或创建真实运行策略。

这些是功能与故障路径验收，不是长期试运行证明。尚需真实浏览器视觉/可访问性验收、持续多周模拟观察、硬断电和不同机器恢复验证，以及对外使用所需的数据授权、身份权限和部署运维设计。当前仅绑定本机回环地址，不对公网开放。

源码压缩包排除运营数据库、快照、用户记录、备份、日志与缓存。升级前请先创建备份；不要用源码包覆盖这些运行数据。


## 因子有效性与研究证据

多因子模块新增 IC / Rank IC、三组远期收益、1/5/20 日因子衰减和训练选择因子的滚动样本外检验，至少需要 5 只股票和 240 个共同观测日。机器学习模块新增逐折误差与基线对照、横截面 Rank IC 和完整切分边界。操作、公式、抽样和证据限制见 [因子验证说明](FACTOR_VALIDATION.md)。

## 组合优化与样本外对照

组合模块新增独立的「组合算法实验」，将 Ledoit–Wolf / 样本协方差用于等权、波动倒数、风险平价约束近似和受约束最小方差。按前期收盘估计、后续开盘做连续股数研究；统一比较净值、回撤、目标权重、风险贡献、换手及成本。目标上限仅约束调仓时刻，风险无法均分时披露残差。该实验不修改手工持有组合、运营账户或启用策略。操作、资金核对和研究限制见 [组合优化说明](PORTFOLIO_OPTIMIZATION.md)。

## 状态算法研究

市场状态页面新增 HMM、KMeans 与阈值马尔可夫的独立对照实验。固定训练窗拟合与标准化，测试期逐日前向过滤；按共同的下一日收益及上涨事件评估，不把状态概率直接当作涨跌概率。七张图展示状态差异、过滤分布、训练特征、转移矩阵、Brier、可靠性及状态后续收益；导出各折模型参数和逐日预测。详见 [状态研究说明](REGIME_RESEARCH.md)。
