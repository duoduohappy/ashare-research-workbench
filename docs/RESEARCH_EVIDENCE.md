# 研究证据库：数据版本与离线复现

在「数据质量与来源」页面进入「研究证据库」。该功能与运营策略的快照分开，服务于交互式因子、组合、状态和策略稳健性研究，不创建或启用交易账户。

## 使用流程

1. 加载行情或合成演示，选择共享截止日期。
2. 输入 1–8 只沪深普通股票，点击「冻结共享截止日的日线」。任一标的获取或检查失败时不保存部分股票池。
3. 选择冻结数据版本及研究类型；单标的状态/策略研究另选目标代码。
4. 点击「读取并预览当前研究参数」，核对对应研究面板的设置，再运行并保存。
5. 选择已保存的研究记录，点击「离线复算并核对完整结果」。
6. 选择左右两个版本进行日线差异比较，或导出日线快照与研究记录。

因子和组合使用所选快照全部股票；状态及策略验收使用选定代码。各研究原有最小样本要求仍适用：冻结成功不代表足以完成所有研究。

## 冻结的数据

保存截至指定日期的规范化日线：日期、复权收盘、原始 OHLC 和成交量，附每个来源说明。每只标的需要 30–2000 根递增且不重复的有效日线，检查正有限价格、非负成交量及原始 OHLC 边界。

仅保存目前可得的规范化日线，没有保存供应商完整原始响应、财报、新闻、分钟线或全市场历史股票池。公共接口的修订数据不能靠冻结还原为过去未曾捕获的版本；本功能从捕获时起积累版本，不提供完整历史 PIT。

股票池、截止日期、数据模式、来源说明和日线共同决定快照 SHA-256。完全相同的负载复用同一版本；不同截止日期即使没有新增交易日，也可能形成不同编号。

获取时间和缓存标记保存在首次捕获的校验记录中，不参与日线负载标识；后续相同数据不覆盖首次元数据。缓存未标过期也不等于数据完整或实时，页面同时展示实际首末日期。

## 内容校验与保存

文件按明确 schema 和 JSON 规范化序列化计算哈希，拒绝 NaN/Infinity。记录外层保存校验值；快照还验证文件编号与日线负载哈希相同，研究记录额外验证结果哈希。

写入先完成临时文件，再发布为创建专用的目标文件。Windows 使用不覆盖已有目的文件的原子重命名；POSIX 使用创建专用硬链接。接口不覆盖已有记录，异常或校验失败不会静默修复为另一份数据。

这些是完整性校验，不是数字签名、第三方认证或法律取证。能同时修改文件和校验值的本机操作者仍可能改写内容，不能宣称具备防恶意篡改能力。

## 四类研究与参数

| 类型 | 冻结参数来源 | 复算范围 |
| --- | --- | --- |
| 因子验证 | 因子验证面板的价格因子、远期窗口 | IC、分组、衰减和滚动检验 |
| 组合算法实验 | 组合实验的训练窗、调仓、上限、成本等 | 四算法连续权重研究及审计记录 |
| 状态算法对照 | 状态实验的训练窗、阈值及所选代码 | HMM / KMeans / 阈值马尔可夫结果 |
| 策略稳健性验收 | 策略实验候选、资金、过滤及稳健性设置 | 滚动选参、压力、延迟与固定种子重采样 |

冻结数据日期与共享回放日期独立。改变共享日期不会改变既有记录；运行时使用所选快照的截止日，不追加后续行情。参数来自点击运行时的设置，保存后随记录固定。

## 计算环境与复算判定

记录受控研究源码的 SHA-256、Python 版本、机器架构及已加载的 NumPy、SciPy、scikit-learn 版本，汇总成计算环境指纹。受控源码包括证据库自身及相关分析、模型和回测模块；任一受控文件或上述环境字段不同都会阻止复算。

服务运行期间若受控源码发生变化，拒绝继续分析或复算，要求先重启服务，避免用磁盘新源码指纹描述内存旧代码。

复算只读取本地快照、原参数和当前受控函数，限制数值线程为 1，不请求上游行情，不执行记录中的历史源码，不安装旧依赖，不自动切换 Git 版本。环境相符后，比较整个原始与复算结果 JSON 的严格 SHA-256，而不是只比较图中少数指标。

核对结论包括完整哈希一致、结果不一致、环境变化而停止复算。未执行的核对保留为空，不能当作通过。每次完成的核对另存记录；校验失败的损坏原文件保留供调查，不被自动覆盖。数值库或硬件细节未被完全捕获，浮点差异仍可能导致严格哈希不一致，不能把不一致直接等同策略计算错误。

保留原始结果不意味着任何历史版本都可直接重算。本功能没有完整依赖环境归档；源码或依赖升级后，旧结果仍可读取和导出，但当前环境不会被标为复现成功。

## 六张图及差异解释

冻结日线覆盖图、各标的日线数、本地研究类型次数、版本增删/变更数量、共同日期复权收盘变化、原记录与复算关键指标对照。最后一图仅用于阅读；复现判定依据完整结果哈希。

覆盖以股票池日期并集为参照，不是完整交易所日历。新增或删除日期可能来自截止日、上市、停牌和缺失；复权收盘变化可能来自公司行动或供应商修订，不自动判作数据错误。演示与真实模式不做修订比较。来源文字改变可产生新快照标识，但版本差异数量只统计日线字段。

本地清单每类最多展示最近 100 条记录，摘要数量也只统计该清单。未自动删除更早记录。

## 存储、导出和备份

运行数据位于所选数据根目录的 `research_evidence/` 下，包含 `snapshots/`、`runs/`、`checks/`，由 `.gitignore` 排除。不会上传到 GitHub。

**运营控制台的现有备份暂不包含研究证据库。** 请另行备份整个 `research_evidence/` 目录，或导出所需日线快照与原始研究记录。复制证据目录不会安装匹配的旧 Python 或依赖；仍须核对环境。

当前提供查看、冻结、运行、比较、复算和 JSON 导出，没有导入任意历史代码或自动清理记录的接口。

## 验证

`python -m unittest test_research_evidence -v` 覆盖数据标识与首次元数据保留、四类研究在禁止行情请求时复算、环境变化阻断、源码热改阻断、损坏记录校验、结果不一致、版本增删/字段变化及输入/路径拒绝。

隔离 HTTP 界面逻辑测试覆盖冻结、保存、复算、版本比较、导出及独立日期；浏览器脚本仍通过旧版兼容的打包入口加载。测试通过不代表真实浏览器视觉、长期上游稳定性、完整历史 PIT 或投资有效性验收完成。
