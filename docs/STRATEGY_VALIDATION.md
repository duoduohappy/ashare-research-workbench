# 策略稳健性验收

在「策略实验室」页面，保留原有一次 70%/30% 切分实验，并提供独立的「策略稳健性验收」。后者复用页面中的均线/动量候选、资金和状态过滤设置，使用共享标的、查看日期及已加载的状态参数。

## 使用与区间

1. 输入最多九组不重复的均线/动量候选，周期可选 10、20、30、60、90、120。
2. 选择 126 或 252 个观测日的训练窗，以及固定开盘涨跌停限制场景。
3. 点击「运行滚动稳健性验收」，查看七张图和独立测试账户记录。
4. 导出 JSON，核对训练选择、原始交易、成本压力、延迟情景和重采样结果。

预热起点为 `max(状态周期+253, 最大均线周期+1, 最大动量周期+1)`，首个测试窗在其后一个完整训练窗开始，每隔 63 个观测日形成一折。最多展示最近四个完整测试窗，至少两折。默认 20 日状态周期、126 日训练需要至少 525 根日线；252 日训练需要至少 651 根。尾部不足 63 日的部分不评分，页面明确披露数量与实际评估截止日。

区间按输入日线观测步计算，缺失或停牌缺行可能跨多个市场交易日。锚点与预热配置固定时，追加未形成新完整测试窗的数据不会改变已完成折的结果。

## 训练选择与参数稳定性

训练评分 = 累计收益 + 0.5 × 最大回撤，最大回撤为负数。仅训练选参；同分按较小 MA、再较小动量周期打破并列。测试期不计算所有候选的收益排行榜，不按测试结果替换所选参数。

参数热力图展示各训练窗的评分，选择次数图只统计这些训练选择。最多四折的频次不能证明参数普适性；人工反复挑股票、改参数或起止区间仍会产生研究者选择偏差。

所选均线周期、动量周期、状态窗口及阈值保持固定。马尔可夫过滤仍复用主引擎的扩展计数，随每个信号日已知历史因果更新，不是冻结转移矩阵的实验。

## 独立测试账户

每折训练和测试账户分别从指定初始资金开始；测试不继承训练持仓，也不继承上一折账户。测试末持仓按收盘估值、不强制卖出。

图中单折净值以相对观测步 0–63 对齐，0 为首次执行前初始资金的净值 1。不同折的净值和收益不拼接、不复合，摘要只报告平均、中位数和最差单折收益，不能当作连续投资账户的年化或最大回撤。

使用既有回测引擎的整手、T+1、开盘涨跌停保守阻断、零成交量和日期税费近似。基准为同一测试窗、同一资金和成本口径的买入持有。

## 成本和延迟压力

基础成本：每侧佣金 3 bp、最低五元、每侧滑点 10 bp，另外计算既有引擎按日期估计的税费。这里 1 bp = 0.01%。

压力网格为佣金每侧 3/6 bp × 滑点每侧 0/10/30 bp，共六种情景。始终使用原训练选择，不因压力情景重新选参。表格同时提供相同成本下相对买入持有的平均单折超额。整手和价格限制可能改变成交数量、路径与费用，不能假定情景之间净收益严格单调。

延迟情景将信号滞后由 1 个观测日改为 2 个：均线、动量、马尔可夫方向全部取更早的收盘信息。实际开盘价、涨跌停参考、复权换算、成交费用仍取真正执行日。导出记录保留真实信号日和执行日。

回测参数现在显式包含 `signal_lag`，支持 1 或 2，默认 1，保持原研究和运营回测的默认时序。延迟只是操作压力情景，不保证完整刻画实际报单失败或排队。

## 配对移动区块重采样

先逐折计算每日策略净资产收益减同日买入持有净资产收益。首日以初始资金作分母，因此包含建仓成本。统计量为所有已完成测试观测的平均每日配对超额，不是复合收益或策略盈利概率。

每折内部抽取长度 5 的连续非循环区块，拼接并截取到原折长度；不让区块跨越折边界。固定种子 42，重复 500 次，以 2.5%、50%、97.5% 分位数给出区间和中位数，并保存样本分布。

这个区间以已选参数和已有测试时期为条件，没有重新执行训练选择，也没有纠正多重检验、幸存者偏差或历史数据修订。固定块长假定能近似保留短程依赖，折间相关性未单独建模；样本少和结构突变会影响区间。不能将不含零解释为发现稳定 alpha，含零也不能简单证明策略无效。

## 七张图和导出

| 图表 | 内容 |
| --- | --- |
| 独立测试窗收益 | 所选策略与同窗买入持有 |
| 相对步数单折净值 | 各独立资金账户按 0–63 步对齐 |
| 训练评分热力图 | 各候选参数在不同训练窗的表现 |
| 训练选择次数 | MA / 动量组合被训练选择的次数 |
| 成本压力热力图 | 六个情景下的平均单折策略收益 |
| 区块重采样分布 | 固定策略的平均每日配对超额样本分布 |
| 信号延迟对照 | 一日前与两日前信号的单折收益 |

JSON 包含每折训练评分与所选参数、全部基础回测、延迟回测、成本情景、配对日收益差、重采样样本与区间，及完整配置和实际评估范围。输入变化或迟到请求不会恢复旧日期结果。

## 验证和限制

运行 `python -m unittest test_strategy_validation test_research -v`，检查时间截断、完整折稳定、扰动测试价格不改训练选择、并列选择、手工复算成本情景、实际延迟执行时序、重采样复现和首日费用。界面逻辑测试覆盖图表、输入拒绝、日期切换和迟到响应。

本功能不会创建或启用运营策略。所用行情是当前修订版本，不是严格 PIT；单股票及人工候选有选择偏差。既有引擎没有完整历史 ST/IPO 规则、盘口容量、排队、真实公司行动和分红税处理，结果仍是研究近似。合成示例只用于程序验证。

方法参考：[时间序列向前切分](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)、[非循环移动区块重采样](https://arch.readthedocs.io/en/latest/bootstrap/generated/arch.bootstrap.MovingBlockBootstrap.html)、[滑点情景建模](https://www.backtrader.com/docu/slippage/slippage/)。本模块自行实现固定锚点分窗和配对区块采样，未导入 arch 或 Backtrader，也不宣称与其成交模型等价。
